# FC-Marketing

Content workspace for LinkedIn and Instagram/Reels.

## Layout

| Path | What's in it |
|---|---|
| `CLAUDE.md` | Working conventions and skill routing — read by Claude Code each session |
| `brand/` | Brand profile, voice, audience, content pillars |
| `drafts/` | Work in progress, named `YYYY-MM-DD-platform-slug.md` |
| `published/` | Shipped posts, with the live URL at the top |
| `assets/` | Images and video |
| `calendar.md` | Recurring posting rhythm |

## Getting started

The `brand/` files drive everything else — until they exist, generated content
will be generic. Open this folder in Claude Code and run, in order:

1. `brand-profile`
2. `voice-builder` — paste 5–10 of your own best-performing posts
3. `content-pillars`

Content skills are installed globally in `~/.claude/skills/`.
